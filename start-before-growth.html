建议体验顺序

  1. 小程序首页 → 手动切换第2/3张轮播 → 新人礼 / 高校行；两张矮卡片进入政策与紫色“新人安家”。下方继续浏览12套截图参考房型。
  2. 通勤找房 → 输入目的地 → 选择轨交／骑行／步行／驾车与时长 → 查看现有小程序样式的找房结果；政策资讯 → 10项可勾选找房清单。需要推荐好友时，进入具体房间或项目详情，再选择好友或群聊分享。
  3. 后台“好友推荐” → 对待核实记录确认有效 → 对有效咨询录入线下签约成交；回到小程序“我的推荐”查看进度与积分。
  4. 首页“活动专区” → 轻任务、生活笔记、新人礼与积分福利；首页“需求调查” → 三套问卷。“我的”按找房服务、活动与福利、内容与共创、账户服务归类。
  5. 小程序“我的 / 管家共创” → 已通过的管家进入工作台；新建活动或内容后在后台审核。

保存与联动
